# Конфиденциальность

Рабочее название: «Сошлось?». Политика относится к разрабатываемой рекламной alpha-сборке; до публикации требуется подтверждение владельцем. Дата подготовки: 7 ноября 2026.

Приложение хранит график, ставки, смены, начисления, выплаты и историю изменений в закрытом каталоге Android. Регистрация и сервер разработчика не требуются. Геолокация, контакты, SMS и банковские приложения не используются. Финансовые данные не направляются разработчику. Облачная синхронизация отсутствует; автоматические Android backup/device transfer отключены.

Разрешение на уведомления запрашивается только при включении напоминаний и может быть отозвано в Android. WorkManager может выполнять короткие фоновые задания для локальных напоминаний. Постоянная служба отслеживания работы не используется.

CSV сохраняется в выбранное вами место без шифрования. Зашифрованная копия содержит график, ставки, смены, выплаты, сверки и аудит; используется AES-256-GCM с ключом из пароля через PBKDF2-HMAC-SHA256 (210000 итераций, случайная соль). Пароль не хранится. Без него восстановление невозможно. Если вы выбираете облачного поставщика в системном диалоге файлов, дальнейшая обработка файла зависит от этого поставщика.

В настройках можно удалить локальную базу и настройки. Ранее экспортированные файлы удаляйте самостоятельно в месте их хранения. Удаление приложения обычно удаляет его локальные данные; копии во внешних местах остаются.

Рекламный слой использует Yandex Mobile Ads SDK 8.6.0 с техническими компонентами AppMetrica. Автоинициализация отключена. По умолчанию согласия нет: инициализация и запрос баннера выполняются только после разрешения в настройках. Возможны обработка технических/рекламных идентификаторов, IP-адреса, сведений об устройстве, объявлениях и взаимодействиях с ними. Геолокация SDK отключена, разрешений на неё нет. Финансовые записи не передаются в запросы рекламы. После отзыва согласия баннер уничтожается, новые запросы не отправляются; SDK может завершать уже начатые операции. Полное завершение работающих компонентов происходит после закрытия процесса приложения.

В production после согласия также запрашивается публичная конфигурация включения рекламы на raw.githubusercontent.com. GitHub получает обычные сведения HTTP-соединения, включая IP-адрес; финансовые параметры и идентификаторы пользователя к URL не добавляются. При ошибке этой проверки реклама выключена. Рекламная версия имеет сетевые разрешения и AD_ID из SDK. Отдельная продуктовая аналитика и crash reporting разработчику не отправляются.

# План

- M0: запускаемый Android-проект, CI, проверенная защита main.
- M1: настройка графика, локальная база, календарь, подтверждения, чеки, напоминания.
- M2: прогноз, выплаты, сверка, CSV, зашифрованные резервные копии.
- M3: тестовые баннеры Yandex, согласия, доступность, проверка offline.
- M4: UI-тесты, release pipeline, материалы магазинов, закрытая beta.

Этап завершён только при выполнении его критериев. Публикация и юридические действия требуют полномочий владельца.

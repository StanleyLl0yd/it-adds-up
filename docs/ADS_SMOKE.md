# Online-проверка рекламного SDK

Тест AdsNetworkTest запускается отдельно на эмуляторе GitHub Actions после разрешения владельца. Владелец запускает workflow меткой `yandex-smoke-approved` на PR из ветки этого репозитория. Обычные проверки учёта исключают тестовый класс и выполняются отдельно от сети рекламы.

Эмулятор использует искусственные записи и официальный `demo-banner-yandex`. AdRequest содержит ID демоблока. При запросе Яндекс получает IP runner и технические или рекламные идентификаторы тестового эмулятора. Начисления, график и выплаты в запрос не включаются. Тест проверяет загрузку баннера и отзыв согласия.

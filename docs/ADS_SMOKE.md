# Online-проверка рекламного SDK

Готов тест AdsNetworkTest. Он намеренно @Ignore и не выполняется обычным CI: автоматическая проверка безопасности отклонила фактический запрос к Яндексу без отдельного согласия владельца на destination/payload.

После явного разрешения владельца: убрать @Ignore в отдельном PR и запускать только этот класс на отдельном online-эмуляторе GitHub Actions с официальным demo-banner-yandex. Обычные пользовательские тесты остаются offline и исключают этот класс.

Запрос использует IP GitHub runner и технические/рекламные идентификаторы искусственного эмулятора. Суммы, смены, работодатели и выплаты в AdRequest не включаются; запрос создаётся только из публичного официального demo ID. Тест проверяет загрузку и отзыв согласия. Он не подтверждает монетизацию, доход или готовность production ID.

# Архитектура

Один модуль `app` на Kotlin, Compose и Material 3. `domain` содержит чистую арифметику и календарь. `data` хранит график, версии ставок, смены, выплаты, листки и аудит в Room. DataStore отвечает за темы и напоминания. `TrackerViewModel` связывает Flow из хранилища с интерфейсом, а файловые операции выполняет вне UI-потока. Минимум Android 8.0, API 26.

Деньги хранятся в копейках. Почасовые суммы и ночная доплата округляются отдельно до копейки с `HALF_UP`. Моменты начала, окончания и перерывов представлены `Instant` и рабочей зоной. Смена относится к дате начала в рабочем часовом поясе, в том числе при переходе через полночь. Изменение условий создаёт ставку с датой действия. В подтверждённой смене сохраняется собственный снимок условий.

План формируется из графика и явно сохранённых исключений. Он попадает в прогноз, пока пользователь не подтвердил отработанное время. Подтверждение и запись аудита проходят в одной транзакции. Выплаты относятся к выбранному периоду независимо от фактической даты поступления. Сверка использует начисления до удержаний и выплаты после удержаний как отдельные пары сравнения.

Room schema хранится в `app/schemas`. Деструктивного fallback при миграции нет. Резервная копия включает версию, данные и аудит, шифруется AES-256-GCM с паролем через PBKDF2. Восстановление проверяет подлинность и формат до транзакционной замены базы. Настройки интерфейса и согласия в копию не входят. Экспорт и импорт используют Android Storage Access Framework.

Напоминания работают через WorkManager только при включении пользователем. Уведомление об одной смене показывается один раз. Android может задержать проверку из-за ограничений батареи. Приложение не требует точных будильников и геолокации.
